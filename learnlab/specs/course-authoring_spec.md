# Specification: Course Authoring

## Overview
Instructors need the ability to create courses, add modules, and nest lessons within those modules. Courses should begin in a DRAFT state.

## Acceptance Criteria
- AC-AUTHOR-01: Instructor can create a course with title, description, category, and difficulty.
- AC-AUTHOR-02: newly created courses start in DRAFT state.
- AC-AUTHOR-03: Instructor can add modules to a DRAFT course.
- AC-AUTHOR-04: Instructor can add nested lessons to a module.
- AC-AUTHOR-05: Instructors can create quiz questions (MCQ, TRUE/FALSE) for modules.
- AC-AUTHOR-06: Published courses cannot be mutated (modified) without an unpublish transition first.
