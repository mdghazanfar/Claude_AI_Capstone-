# Specification: Progress Tracker

## Overview
Computes and snapshots course progress for each learner.

## Acceptance Criteria
- AC-PROGRESS-01: Course progress percentage is computed as `completed_lessons / total_lessons`.
- AC-PROGRESS-02: Learner can view own progress percentage across enrolled courses.
- AC-PROGRESS-03: Learner can view own quiz scores across enrolled courses.
- AC-PROGRESS-04: A learner cannot access another learner's progress.
- AC-PROGRESS-05: Progress tracking logs are append-only.
